# communications

Drafting and design helpers for church communications — announcements, social
posts, newsletters, and visual assets.

## Installation

### Claude Code

```text
/plugin marketplace add Threefold-Solutions/church-skills
/plugin install communications@church-skills
```

### Codex CLI

Cloning the `church-skills` repo and running Codex inside it loads this plugin
automatically via `.agents/plugins/marketplace.json`.

## Skills

| Skill | Description |
|-------|-------------|
| `screenshot-to-vcard` | Convert a screenshot of contact info into a downloadable `.vcf` vCard |

A Claude.ai web version of `screenshot-to-vcard` also ships at
[`claude-ai-skills/screenshot-to-vcard/`](../../claude-ai-skills/screenshot-to-vcard/)
for staff using Claude in a browser.
